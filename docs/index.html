Why

One glance

Every agent shows its logo with the 5-hour quota on top and the weekly quota below. Orange under 30%, red under 10%.

Full popup

Each limit with a reset countdown, the model in use, and a one-click model switcher.

Multi-account

Add more logins per CLI, each in its own folder. Emails stay hidden until you click them.

Six languages

Tiếng Việt, English, 中文, 日本語, 한국어, Español.

Every desktop

macOS, Windows and Linux.

Private

Talks only to the vendors' own usage endpoints, with the sign-in your CLIs already saved.

Screenshots

Where the numbers come from

AgentSource
ClaudeAnthropic usage API. Token from the macOS Keychain or ~/.claude/.credentials.json.
CodexChatGPT usage API. Token from ~/.codex/auth.json.
Agyagy -p /usage, which prints the quota table without calling a model. Quota is split by model group; the bar uses the group of your selected model.

Build it yourself

./build.sh mac       # native macOS app (Swift)
./build.sh mac-app   # macOS dmg + zip (Electron)
./build.sh win       # Windows installer + portable exe
./build.sh linux     # Linux AppImage + deb

cd desktop && npm install && npm start   # run from source

Pushing a v* tag builds all three platforms on GitHub Actions.
